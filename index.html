Panduan Setup Backend (Supabase + GitHub Pages)

Salin script berikut ke proyek Supabase Anda agar pengiriman WhatsApp berjalan otomatis 24/7

Buat Tabel reminders + Keamanan RLS

Buka Supabase Dashboard → SQL Editor → New Query, tempel lalu klik Run.

Supabase Edge Function (send-wa-reminders)

Simpan token API Anda di Project Settings → Edge Functions → Secrets dengan nama WA_API_TOKEN.

Penjadwalan Otomatis Setiap Menit (pg_cron)

Aktifkan ekstensi pg_cron & pg_net di menu Database → Extensions, lalu jalankan query ini di SQL Editor.

Langkah Ringkas Go-Live (Gratis & Aman)

  1. Buat Akun Admin di Supabase: Masuk ke Authentication → Users → Add User dan buat 1 akun Email & Password khusus untuk Anda. Nonaktifkan pendaftaran publik (Disable Signup) di menu Auth → Providers → Email.
  2. Upload ke GitHub Pages: Buat repository baru di GitHub, upload file index.html ini, lalu aktifkan Settings → Pages → Branch: main.
  3. Hubungkan WebApp: Buka URL GitHub Pages Anda, klik Pengaturan → Mode Produksi, masukkan Project URL dan Anon Key, lalu login dengan akun yang tadi dibuat.
